# Project instructions

## Design direction
- **Elk nieuw project staat los.** Neem geen visuele stijl mee van andere projecten of van een aangehangen design system, tenzij de gebruiker daar in dit project expliciet om vraagt.
- Kies per project een eigen, passende richting op basis van wat het product is.
- Niet gebruiken tenzij gevraagd: de zwart/groene "terminal" stijl, mono-only typografie, `[ ... ]`-bracket labels, scanline/glitch effecten.
- Standaard voorkeur: clean, licht, modern product-UI.

## Taal
- UI-teksten en labels in het Engels; gesprek in het Nederlands.
